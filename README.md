# Survey-Bot
# 📊 SurveyBot — Telegram-бот для опросов

Бот на **aiogram 3.x** + **SQLite**, готовый к деплою на **Render**.

---

## 🗂 Структура проекта
survey-bot-demo/
├── main.py # точка входа (Flask + aiogram)
├── database.py # вся работа с SQLite
├── keyboards.py # клавиатуры и форматирование
├── requirements.txt
├── .python-version # фиксация версии Python 3.13
└── handlers/
├── init.py
├── client.py # команды клиента
└── admin.py # команды администратора (демо-режим)

---

## ⚙️ Переменные окружения

| Переменная | Описание |
|------------|----------|
| `BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) |

> **ADMIN_ID не требуется** — админ-панель работает в демо-режиме для всех.

---

## 🚀 Локальный запуск

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Задать переменные окружения
export BOT_TOKEN="your_token_here"

# 3. Запустить
python main.py
```
☁️ Деплой на Render
Создайте Web Service (не Background Worker, чтобы работал Flask).

Укажите Start Command: python main.py

В разделе Environment Variables добавьте BOT_TOKEN.

Render сам установит порт 10000 через переменную PORT.

🤖 Команды бота
Клиент
Кнопка	Действие
Пройти опрос	Выбор опроса из списка и пошаговое прохождение
Мои ответы	Просмотр своих предыдущих ответов
Контакты	Ссылка на разработчика
Администратор (Админ-панель)
Команда	Действие
Создать опрос	Пошаговое создание опроса (название → вопросы → варианты)
Все опросы	Просмотр всех опросов
⚠️ Демо-режим: созданные опросы не сохраняются в базу данных. Это витрина для демонстрации функционала.

✅ Возможности
Создание опросов с разными типами вопросов (текст, выбор, да/нет)

Пошаговое прохождение опросов

Сохранение ответов в базе данных

Просмотр истории своих ответов

Админ-панель для создания опросов

Flask keep-alive предотвращает засыпание сервиса на Render
